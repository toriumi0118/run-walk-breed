## Phase 1: コアゲームループ

Godot 内で完結するゲームの中核部分。ネイティブ連携なしで動作確認できる状態を目指す。

### 1-1. ペットシステム

- [ ] ペットデータモデル（Resource クラス）
  - ステータス: HP, 攻撃, 防御, 素早さ
  - レベル、経験値
  - 習得スキルリスト
  - タイプ（Runner, Walker, Sprinter）
- [ ] ペット生成・初期化ロジック
- [ ] ペットの表示（スプライト / アニメーション）

### 1-2. 育成システム

- [ ] 歩数 → 経験値の変換ロジック
- [ ] レベルアップ処理とステータス成長曲線
- [ ] スキル習得条件と習得処理
- [ ] 育成状況の永続化（ローカルセーブ）

### 1-3. スキルシステム

- [ ] スキルデータモデル（Resource クラス）
  - 名前、タイプ、威力、命中率、消費コスト等
  - 効果（ダメージ、バフ、デバフ、回復 etc.）
- [ ] スキル一覧のマスタデータ管理
- [ ] バトル前のスキル構成選択 UI（最大 4 スロット）

### 1-4. オートバトルシステム

- [ ] バトルエンジン（ターン制 or リアルタイムオート）
  - ターン順序の決定（素早さベース）
  - スキル選択 AI（自動行動ロジック）
  - ダメージ計算式（攻撃 vs 防御、属性相性等）
  - 勝敗判定（HP 0 or ターン上限）
- [ ] バトル画面 UI
  - ペットのアニメーション表示
  - HP バー、ターン表示
  - スキル発動演出
  - 勝敗結果画面
- [ ] バトル報酬（経験値、アイテム等）

### 1-5. ホーム画面

- [ ] ペットの状態表示（ステータス、レベル）
- [ ] 画面遷移（ホーム ↔ 育成詳細 ↔ スキル編成 ↔ バトル ↔ 地図 ↔ 設定）
- [ ] 歩数・距離のサマリ表示（ダミーデータで）

### 1-6. ローカルデータ管理

- [ ] セーブ/ロード機構（JSON or ConfigFile）
- [ ] ペットデータ、育成進捗、スキル構成の永続化
- [ ] 設定データ（音量、通知等）の永続化
